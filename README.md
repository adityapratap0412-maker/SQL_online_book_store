# 📚 SQL Online Book Store Analysis

**Project Type:** Data Analyst SQL Project  
**Tool:** MySQL Workbench

## 📌 Project Overview
This project focuses on analyzing an online bookstore's data using SQL to understand customer spending, book sales, monthly revenue trends, and inventory performance.

The goal is to extract meaningful business insights and support data-driven decision-making.

## 🗂️ Database Tables
- **Customers:** Customer details, including name, email, city, and country.
- **Books:** Book details, including title, author, genre, price, and stock.
- **Orders:** Order details, including customer ID, book ID, order date, quantity, and total amount.

## 🔍 Business Questions & SQL Analysis

### 1. Highest-Spending Customer
Identified the customer who spent the most based on their total order amount.

**SQL Concepts:** JOIN, SUM(), GROUP BY, ORDER BY, LIMIT

### 2. Book Stock and Order Quantity
Analyzed book stock and total ordered quantities to understand inventory and book demand.

**SQL Concepts:** LEFT JOIN, SUM(), COALESCE(), GROUP BY

### 3. Monthly Revenue Growth
Calculated monthly revenue and compared it with the previous month to analyze revenue growth.

**SQL Concepts:** CTEs, LAG(), Window Functions, DATE_FORMAT(), NULLIF()

### 4. Top 3 Best-Selling Books by Genre
Ranked books within each genre based on total quantity sold and identified the top three books in each genre.

**SQL Concepts:** CTEs, SUM(), ROW_NUMBER(), Window Functions

### 5. Customer Segmentation
Segmented customers into High Value, Medium Value, and Low Value groups based on total spending.

**SQL Concepts:** CTEs, CASE WHEN, LEFT JOIN, COALESCE()
