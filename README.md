# SQL Online Book Store Project

**Project type:** Data Analyst SQL project  
**Tool:** MySQL Workbench

## Project screenshots

This folder contains screenshots of SQL queries and their outputs, including:

1. Customers with orders over $30
2. Highest-spending customer
3. Book stock, ordered quantity, and remaining stock
4. Monthly revenue and month-over-month growth
5. Top 3 best-selling books in each genre
6. Customer segmentation by total spending
7. Low-stock, high-demand books (query screenshot)

The screenshots show selected queries and result grids from the project. They are provided as visual evidence of the SQL analysis.

## Skills demonstrated
- SELECT, JOIN, LEFT JOIN
- WHERE, GROUP BY, ORDER BY
- Aggregate functions such as SUM
- CTEs (`WITH`)
- Window functions such as `LAG()` and `ROW_NUMBER()`
- `CASE WHEN`, `COALESCE()`, and date formatting
- Revenue growth and customer segmentation analysis
